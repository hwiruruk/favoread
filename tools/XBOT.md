# X(트위터) 게시 도우미

X API를 쓰지 않는 반자동 봇입니다. 글과 이미지는 자동으로 준비되고,
게시 버튼만 사람이 누릅니다. 그래서 **비용이 0원**이고 계정 정지 걱정도 거의 없습니다.

## 매일 하는 일 (1~2분)
1. `https://favorbook.co.kr/xbot/` 을 엽니다. (검색엔진에는 안 잡히는 운영자용 페이지)
2. 트윗 카드마다
   - **이미지 모두 저장** (PC에서는 한 장씩 **복사**해 붙여넣어도 됨)
   - **𝕏 X에 쓰기** → 글이 채워진 작성창에 이미지를 순서대로 첨부하고 게시
     (PC에서는 누를 때 1번 이미지가 클립보드에 복사돼 있어 Ctrl+V 한 번으로 붙음.
     X 공유 링크는 이미지를 넘길 수 없어서 완전 자동은 안 됨)
   - 폰에서는 **공유** 버튼 한 번으로 글+이미지를 X 앱에 넘길 수 있어요(기기마다 다름)
   - 다 올렸으면 **올렸어요**
3. 🧵 타래가 있는 카드: 첫 글을 올린 뒤 그 글 주소를 칸에 붙여넣고 **답글 쓰기** →
   앞 글에 답글로 이어진 작성창이 열립니다. 답글이 여럿이면 같은 식으로 이어 갑니다.
   (붙여넣은 주소는 이 브라우저에 기억됩니다)
4. **출처 확인**을 펼치면 책마다 원문을 열어 볼 수 있습니다. 데이터 편집기(/editor/)의 책 카드와
   책 편집 창에도 **출처 열기** 버튼이 있습니다.
5. 글은 카드의 칸에서 바로 고칠 수 있고, 280자 계산도 같이 보여 줍니다.
6. **✍️ 인물 골라서 만들기**: 인물을 고르고 책을 최대 6권 체크하면 같은 모양의 트윗을 그 자리에서 만듭니다.
   이미 나간 책은 '나감'으로 표시되고, 기본으로는 안 나간 책부터 골라 둡니다.
   재료는 매일 도는 작업이 만드는 `data/x_books.json` 입니다. 직접 만든 트윗은 '나간 책' 기록에 들어가지 않으니
   같은 책이 나중에 매일 트윗에 다시 나올 수 있습니다.
7. **📷 사진 올리기**: '읽은 사람 모여라' 카드에서 내 사진을 맨 앞 동그라미로 넣을 수 있습니다
   (책장 카드는 책 정보 장만 있어 사진 도구가 숨겨집니다). 사진은 브라우저 안에서만 쓰이고
   어디에도 올라가지 않습니다(새로고침하면 사라짐). ✕로 뺍니다.
8. **인물 사진** 체크로 사진을 넣거나 뺍니다. 배경은 오른쪽 위에서 흰색·상아색 중에 고릅니다.

  `data/x_sources.json` 에 모아 둡니다(한 번 읽은 곳은 다시 안 읽음).

## 투명 배경
- 게시 도우미 오른쪽 위 배경에서 **투명**을 고르면 배경 없는 PNG로 저장됩니다.
- X의 어두운 화면에서도 보이도록, 바탕 위에 바로 쓰는 글자에는 흰 테두리를 얇게 둘러 줍니다.
- 사이트 책장 페이지(share, en/share)의 **⤓ 투명 배경** 버튼도 같은 방식으로 종이색 없이 저장합니다.

## 채팅 디자인
- 게시 도우미 오른쪽 위 **기본 / 채팅**으로 고릅니다.
- '최애의 독서'가 채팅방에서 책을 소개하는 모양입니다. 말하는 사람은 언제나 '최애의 독서'이고,
  인물 본인이 보낸 메시지처럼 꾸미지 않습니다(인물 이름으로 된 말풍선·인증 마크·1인칭 없음).
- 편집기 **💬 코멘트 검수**에서 승인한 코멘트가 있는 책은 그 글을 출처와 함께 말풍선으로 붙입니다.
  코멘트를 많이 승인할수록 채팅 디자인이 풍성해집니다.

## 이미지 (X 모바일에서 안 잘리는 비율)
- 책 정보 장만 만듭니다(표지·제목·저자|출판사·출처). 표지만 모은 장과 쪽 번호·#번호는 없습니다.
- 책장 1~2권: 16:9 한 장 / 3~4권: 8:9 두 장(2권씩) / 5~6권: 16:9 네 장(2×2 격자)
- 이 책을 읽은 셀럽들: 1장, 1:1 — 책 표지 + 인물 사진 줄(선택) + 이름

## 자동으로 돌아가는 것
- `.github/workflows/x-queue.yml` 이 매일 **07:00 KST** 에 `tools/x_queue.py` 를 돌려
  `data/x_queue.json` 에 오늘 치 3개를 넣습니다. 최근 7일 치가 남아서 놓친 날도 올릴 수 있어요.
- 하루 3칸
  1. **새로 추가** — 어제 이후 data.csv 에 새 책이 들어온 인물. 없으면 셀럽 책장
  2. **이 책을 읽은 셀럽들** — 3명 이상이 읽은 책. 처음엔 많이 읽힌 책부터
  3. **셀럽 책장** — 2권 이상인 인물. 처음엔 '요즘 핫한 사람'(featured.json)부터
- 셀럽 책장은 **시리즈**입니다. 한 편에 최대 6권, 이미 나간 책은 빼고 #1, #2 … 로 이어 갑니다.
- 한 편은 **타래**입니다. 첫 글에 들어가는 만큼 책을 쓰고, 못 넣은 책은 답글로 이어 씁니다.
  이미지(최대 4장)는 첫 글에 붙입니다.
- 같은 인물·책은 한 바퀴를 다 돌 때까지 다시 나오지 않습니다. 기록은 `data/x_state.json`.

## 손으로 돌리기
- GitHub → Actions → **X Queue** → Run workflow
  - `force` 를 켜면 오늘 치를 새로 뽑습니다(원래 뽑혔던 인물·책은 다시 후보로 돌아감).
- 터미널에서는
  ```
  python3 tools/x_queue.py --dry-run   # 결과만 보기
  python3 tools/x_queue.py --force     # 오늘 치 다시 만들기
  ```

## 문구 바꾸기
`tools/x_queue.py` 의 `make_celeb_item` · `make_new_item` · `make_book_item` 안에 있는
`heads`(첫 줄)와 `tail`(링크·해시태그)을 고치면 됩니다. 첫 줄은 날짜마다 돌아가며 씁니다.
