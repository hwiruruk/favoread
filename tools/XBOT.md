# X(트위터) 게시 도우미

X API를 쓰지 않는 반자동 봇입니다. 글과 이미지는 자동으로 준비되고,
게시 버튼만 사람이 누릅니다. 그래서 **비용이 0원**이고 계정 정지 걱정도 거의 없습니다.

## 매일 하는 일 (1~2분)
1. `https://favorbook.co.kr/xbot/` 을 엽니다. (검색엔진에는 안 잡히는 운영자용 페이지)
2. 트윗 카드마다
   - **이미지 모두 저장** (PC에서는 한 장씩 **복사**해 붙여넣어도 됨)
   - **𝕏 X에 쓰기** → 글이 채워진 작성창에 이미지를 순서대로 첨부하고 게시
   - 폰에서는 **공유** 버튼 한 번으로 글+이미지를 X 앱에 넘길 수 있어요(기기마다 다름)
   - 다 올렸으면 **올렸어요**
3. 글은 카드의 칸에서 바로 고칠 수 있고, 280자 계산도 같이 보여 줍니다.
4. **인물 사진** 체크로 사진을 넣거나 뺍니다. 배경은 오른쪽 위에서 흰색·상아색 중에 고릅니다.

## 글 모양
```
📚 카리나(에스파)의 책장

📘 모순(양귀자 | 쓰다) *260101 조선일보
🌰 아몬드(손원평 | 다즐링) *260104 @yujasyrup

전체 목록(58권)
https://favorbook.co.kr/s/karina-aespa.html

#최애의독서 #카리나 #에스파
```
- 출처는 X면 `@계정`, 언론·매체면 매체명, 날짜는 `260101` 형식. 280자에 들어가는 만큼만 넣고
  나머지 책은 이미지에만 나옵니다.
- 출처 앞 `*` 는 `tools/x_queue.py` 의 `SRC_MARK` 한 줄로 바꿉니다.
- 제목 앞 이모지는 제목 낱말로 자동 선택. 틀리면 `data/x_emoji.json` 에 `"책 제목": "이모지"` 로 적습니다.
- 출처 날짜: X 게시물은 주소에서 바로 계산, 기사는 주소의 날짜나 원문의 발행일을 읽어
  `data/x_sources.json` 에 모아 둡니다(한 번 읽은 곳은 다시 안 읽음).

## 이미지 (X 모바일에서 안 잘리는 비율)
- 책장 3권 이상: 4장, 16:9 — 표지(인물 사진 또는 표지 모음 + 이름 + 작게 #1) + 책 2권씩 3장
- 책장 2권 이하: 2장, 8:9 — 표지 + 책
- 이 책을 읽은 셀럽들: 1장, 1:1 — 책 표지 + 인물 사진 줄(선택) + 이름

## 자동으로 돌아가는 것
- `.github/workflows/x-queue.yml` 이 매일 **07:00 KST** 에 `tools/x_queue.py` 를 돌려
  `data/x_queue.json` 에 오늘 치 3개를 넣습니다. 최근 7일 치가 남아서 놓친 날도 올릴 수 있어요.
- 하루 3칸
  1. **새로 추가** — 어제 이후 data.csv 에 새 책이 들어온 인물. 없으면 셀럽 책장
  2. **이 책을 읽은 셀럽들** — 3명 이상이 읽은 책. 처음엔 많이 읽힌 책부터
  3. **셀럽 책장** — 2권 이상인 인물. 처음엔 '요즘 핫한 사람'(featured.json)부터
- 셀럽 책장은 **시리즈**입니다. 한 편에 최대 6권, 이미 나간 책은 빼고 #1, #2 … 로 이어 갑니다.
- 같은 인물·책은 한 바퀴를 다 돌 때까지 다시 나오지 않습니다. 기록은 `data/x_state.json`.

## 손으로 돌리기
- GitHub → Actions → **X Queue** → Run workflow
  - `force` 를 켜면 오늘 치를 새로 뽑습니다(원래 뽑혔던 인물·책은 다시 후보로 돌아감).
- 터미널에서는
  ```
  python3 tools/x_queue.py --dry-run   # 결과만 보기
  python3 tools/x_queue.py --force     # 오늘 치 다시 만들기
  ```

## 문구 바꾸기
`tools/x_queue.py` 의 `make_celeb_item` · `make_new_item` · `make_book_item` 안에 있는
`heads`(첫 줄)와 `tail`(링크·해시태그)을 고치면 됩니다. 첫 줄은 날짜마다 돌아가며 씁니다.
