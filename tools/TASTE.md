# 독서 취향 통계

셀럽 페이지(한국어·영문)에 📊 독서 취향을 붙입니다. 분야와 작가를 세어 믿을 만한 것만 한두 줄로 보여줍니다.

```
1. 분야 수집   알라딘에서 책 분야를 찾아 data/genres.json 에 저장   ← Fetch Book Genres 액션
2. 통계 계산   generate.py 가 빌드 때 tools/taste.py 로 계산        ← 사이트 갱신 때 저절로
```

## 나오는 조건 (tools/taste.py 맨 위 상수)

| 조건 | 기준 |
|------|------|
| 책 수 | 5권 미만이면 아무것도 안 나옵니다 |
| 분야 | 분야를 아는 책이 5권 이상이고 전체의 70% 이상 |
| 분야로 꼽히려면 | 3권 이상, 비중 30% 이상, 사이트 전체 평균보다 높음 (최대 2개) |
| 작가로 꼽히려면 | 서로 다른 작품 2권 이상 (한 권짜리 작가는 안 나옴, 시리즈는 1작품, 최대 3명) |
| 참고 코멘트 | 꼽힌 분야·작가의 책 중 코멘트가 붙은 첫 권을 한 줄 덧붙임 |

분야도 작가도 조건을 못 채우면 그 섹션 자체가 안 나옵니다.

## 자동으로 도는 방식

`Fetch Book Genres` 워크플로가 매일 한 번 깨어나 분야를 모르는 책을 셉니다.
**10권 이상 모였을 때만** 알라딘을 조회하고 PR을 올립니다. 기준은 워크플로의 `MIN_BATCH` 입니다.
새 셀럽이 들어와도 똑같습니다. 그 사람 책의 분야가 채워지면 다음 빌드에서 취향이 붙습니다.

손으로 돌리려면 Actions → Fetch Book Genres → Run workflow (권수와 상관없이 조회).
필요한 Secret은 `ALADIN_TTB_KEY` 하나입니다 (책등 워크플로와 같은 값).

PR을 머지하면 사이트 갱신 워크플로가 돌아 페이지에 반영됩니다.

## 틀린 분야 고치기

`data/genres.json` 의 `field` 를 직접 고치면 됩니다. 이미 있는 책은 다시 조회하지 않으므로 덮어쓰이지 않습니다.
분야 이름 목록은 `tools/taste.py` 의 `FIELD_EN` 을 보세요.

로컬에서 확인: `python3 tools/fetch_genres.py --count`
