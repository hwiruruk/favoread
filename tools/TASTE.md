# 독서 취향 통계

셀럽 페이지(한국어·영문)에 📊 독서 취향을 붙입니다. 분야·작가·번역서 비율·출간 시기·분량을 세어
믿을 만한 것만 몇 줄로 보여줍니다.

```
1. 책 정보 수집    예스24 API에서 번역서 여부·출간일·쪽수·시리즈를 받아 data/bookinfo.json 에 저장   ← Fetch Book Info 액션
2. 분야 수집       예스24 카테고리(국내도서 > 소설/시/희곡 > 한국소설 …)를 받아
                   data/categories.json 에 저장                                                     ← Fetch Book Categories 액션
3. 통계 계산       generate.py 가 빌드 때 tools/taste.py 로 계산                                    ← 사이트 갱신 때 저절로
```

작가는 `data.csv` 에 이미 있어서 1·2단계 없이도 나옵니다. 출판사는 취향이라 보기 어려워 세지 않습니다.

## 분야 (예스24 카테고리)

분야는 서점 분류를 그대로 씁니다. 책마다 표지 URL에 든 예스24 상품 번호로 카테고리 경로를 받습니다.

1. 예스24 Open API itemDetail 응답에 카테고리 필드가 있으면 그걸 쓴다 (`YES24_PROXY`/`YES24_API_KEY` 가 있을 때)
2. 없으면 예스24 상품 페이지의 '카테고리 분류' 칸을 읽는다 (키가 필요 없다)

API 응답에 카테고리가 있는지 문서로 확인하지 못해 둘 다 봅니다. 첫 실행 로그에 API 응답의 카테고리 필드가 찍히고,
책마다 어디서 받았는지 `from`(api · page)에 남습니다.
처음 다섯 권이 연달아 카테고리를 못 읽으면(페이지 구조가 바뀌었거나 막혔으면) 그 자리에서 멈추고 응답 앞부분을 로그에 찍습니다.

예전에는 국립중앙도서관·도서관 정보나루의 도서관 분류(KDC)를 썼습니다. 810(한국문학)처럼 문학인 것만 알고
소설인지 시인지 모르는 책이 많고, 만화·자기계발서가 문학·경영으로 들어가 서점 감각과 어긋나서 뺐습니다.

한 책이 여러 카테고리에 걸려 있으면 예스24가 적은 순서대로 모두 받아 두고, 분야는 첫 경로(대표 분류)로 정합니다.
첫 경로로 분야를 못 정하면 다음 경로를 봅니다.

### 예스24 카테고리 → 분야 (`tools/taste.py` 의 `path_genre()`)

국내도서 바로 아래 분류 이름으로 정합니다. 위에서부터 맞춰 봅니다.

### 애매한 책은 편집기에서 직접 (🏷️ 분야 검수)

카테고리가 `소설/시/희곡`까지만 있거나 `고전문학`처럼 소설인지 시인지 모르는 책,
예스24에 카테고리가 없는 책은 편집기 상단 **🏷️ 분야 검수** 창에 모입니다.
여러 카테고리가 서로 다른 분야를 가리키는 책은 '카테고리끼리 다름'에서 따로 볼 수 있습니다 (대표 분류를 쓰니 확인은 선택).
분야 버튼을 누르고 저장하면 `data/genres.json` 에 커밋되고, `taste.py` 는 이 값을 자동 분류보다 먼저 씁니다.
'통계에서 뺌'(`제외`)을 고르면 그 책은 분야 통계에 들어가지 않습니다.
`categories.json` 에 직접 쓰지 않는 이유: 수집 워크플로 PR이 그 파일을 통째로 갈아 끼우기 때문입니다.

분야 목록은 `tools/taste.py` 의 `GENRE_EN` 과 `editor/app.js` 의 `GENRES` 두 곳에 있습니다 (같이 고칠 것).
카테고리 → 분야 규칙도 `tools/taste.py` 의 `_Y24_TOP`·`path_genre()` 와 `editor/app.js` 의 `Y24_TOP`·`y24PathGenre()` 두 곳에 있습니다.

### 나오는 문장

- 주로 읽는 분야: 소설 12권, 에세이 6권, 인문 4권 (분야를 아는 30권 중). — 분야를 아는 책이 5권 이상, 전체의 70% 이상일 때 늘 나온다
- 국내 작가의 책 6권, 번역서 17권이에요 (23권 중). — 국내·해외를 아는 책이 5권 이상, 전체의 70% 이상일 때 늘 나온다

다른 셀럽이나 사이트 평균과 비교하는 문장은 쓰지 않습니다. 그 사람의 독서 기록을 그대로 셉니다.

## 나오는 조건 (tools/taste.py 맨 위 상수)

| 조건 | 기준 |
|------|------|
| 책 수 | 5권 미만이면 아무것도 안 나옵니다 |
| 번역서·출간 시기·분량 | 그 정보가 확인된 책이 5권 이상이고 전체의 70% 이상 |
| 위 세 가지가 말해지려면 | 국내·번역서 권수는 늘 말함. 최근 출간·분량은 그 사람 책의 50% 이상일 때 |
| 작가 | 서로 다른 작품 2권 이상 (한 권짜리 작가는 안 나옴, 1권·2권, 상·하는 1작품, 최대 3명) |
| 참고 코멘트 | 꼽힌 작가의 책 중 코멘트가 붙은 첫 권을 한 줄 덧붙임 |

어느 것도 조건을 못 채우면 섹션 자체가 안 나옵니다. "두꺼운 책" 기준은 500쪽 이상, "가벼운 분량"은 250쪽 이하입니다.
"최근"은 올해 포함 2년입니다. 고전의 개정판은 출간일이 최근으로 잡히니, 최근 출간은 절반을 넘을 때만 말합니다.

## 자동으로 도는 방식

`Fetch Book Info` 워크플로가 매일 한 번 깨어나 정보를 모르는 책을 셉니다.
**10권 이상 모였을 때만** 예스24를 조회하고 PR을 올립니다. 기준은 워크플로의 `MIN_BATCH` 입니다.
새 셀럽이 들어와도 똑같습니다. 그 사람 책의 정보가 채워지면 다음 빌드에서 취향이 붙습니다.
표지가 예스24가 아닌 책은 조회하지 않고 통계에서 빠집니다.

손으로 돌리려면 Actions → Fetch Book Info → Run workflow (권수와 상관없이 조회).
필요한 Secret은 `YES24_PROXY` 또는 `YES24_API_KEY` 입니다 (책등 워크플로와 같은 값).

PR을 머지하면 사이트 갱신 워크플로가 돌아 페이지에 반영됩니다.

## 첫 실행 뒤에 확인할 것

예스24의 `series`(시리즈 번호)는 받아 두지만 작품을 묶는 데 쓰지 않습니다. 출판사 전집(민음사 세계문학전집 61권)이나
작가 모음(한강 작품 전부)까지 한 시리즈로 들어 있어서, 서로 다른 책이 한 작품으로 묶이기 때문입니다.

번역서 판정은 예스24 카테고리로 합니다 (`tools/taste.py` 의 `_origin()`). 문학·에세이 카테고리의 나라 단계가
한국소설·한국 에세이면 국내, 영미소설·일본소설·외국 에세이처럼 다른 나라면 번역서입니다. 인문·경제 같은 책은 나라가
없어 모름으로 둡니다. `bookinfo.json` 의 `translated`(예스24 원제 칸)는 쓰지 않습니다. 예스24가 한국 책에도
해외판 제목을 원제로 적어서(채식주의자 → The Vegetarian) 한국 소설이 번역서로 잡혔기 때문입니다.

## 틀린 값 고치기

`data/bookinfo.json` 을 직접 고치면 됩니다. 이미 있는 책은 다시 조회하지 않으므로 덮어쓰이지 않습니다.

분야가 틀렸으면 편집기 🏷️ 분야 검수에서 고르면 됩니다 (`data/genres.json`). 규칙 자체가 틀렸으면 위 두 곳의 표를 고칩니다.

로컬에서 확인: `python3 tools/fetch_bookinfo.py --count`, `python3 tools/fetch_categories.py --count`
