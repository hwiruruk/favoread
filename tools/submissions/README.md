# 제보 시트 기록기 (Apps Script)

편집기 **📮 제보 반영** 창이 구글 폼 제보 시트에 처리 상태를 적을 때 쓰는 웹앱입니다.
읽기는 공개 시트의 CSV 내보내기로 하므로 이게 없어도 창은 열리고 판정도 보이지만,
시트에 체크·색을 적으려면 한 번 설치해야 합니다. 구글 시트는 로그인해야 고칠 수 있어서
브라우저(편집기)가 직접 쓰지 못하고, 시트 주인 계정으로 도는 이 스크립트가 대신 씁니다.

| 시트 | ID |
|------|----|
| 영문 제보 | `1J4B0pa2Hv3l4nNfzMwghqWHdXT7cUbFZE3gPY1gCzvk` |
| 해외 제보 | `186gKVna6LANvKkdvqJF7V3MTSZdDgI3xksmOgY4WtGM` |

## 시트에 생기는 것

응답 칸(타임스탬프·이름·내용·출처) 바로 오른쪽에 네 칸을 만듭니다.

| 칸 | 내용 |
|----|------|
| 반영 | 체크박스. 반영일 때만 체크 |
| 상태 | `반영` / `보류` / `미반영` — 편집기는 이 칸을 읽어 목록을 거른다 |
| 편집기 메모 | 보류 이유 등 |
| 처리 시각 | 마지막으로 적은 시각 |

행 전체 배경색도 바꿉니다: 파랑 `#cfe2ff` 반영 · 노랑 `#fff2b3` 보류 · 빨강 `#ffd0d0` 미반영.
`setup()`을 돌리면 새 제보가 들어올 때 자동으로 빨간색(미반영)이 칠해집니다.

시트에서 손으로 `상태` 칸을 고쳐도 됩니다. 편집기는 그 값을 따릅니다(색은 다음에 편집기가 적을 때 맞춰짐).

## 설치 (5분)

1. 두 시트의 주인 계정으로 https://script.google.com → **새 프로젝트**
2. `Code.gs` 내용을 통째로 붙여넣고 저장 (프로젝트 이름은 아무거나, 예: favorbook 제보)
3. 위 함수 목록에서 `setup` 을 고르고 **실행** → 권한 승인 (시트 읽기·쓰기, 트리거)
   - **실행 로그**에 `EDITOR_KEY = …` 가 찍힙니다. 이 값을 복사해 두세요
     (나중에 다시 보려면 프로젝트 설정 → 스크립트 속성)
4. **배포 → 새 배포 → 유형: 웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - 배포 → 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`) 복사
5. 편집기 📮 제보 반영 → **⚙️ 시트 연결**에 URL과 EDITOR_KEY를 넣고 **연결 테스트** → **저장**

"모든 사용자"로 열어도 EDITOR_KEY가 맞지 않으면 아무것도 쓰지 않습니다. 키는 편집기를 쓰는 브라우저의
localStorage에만 저장됩니다. 키가 새어 나갔으면 스크립트 속성에서 `EDITOR_KEY`를 지우고 `setup`을 다시 돌리세요.

`Code.gs`를 고친 뒤에는 **배포 관리 → 수정 → 버전: 새 버전**으로 다시 배포해야 반영됩니다(URL은 그대로).

## 편집기가 보내는 것

```json
{ "key": "EDITOR_KEY", "sheet": "intl",
  "updates": [{ "row": 12, "ts": "2026. 9. 29 오전 3:51:16", "status": "반영", "note": null }] }
```

`row`가 그새 밀렸으면(행 삽입·정렬) 타임스탬프 `ts`로 행을 다시 찾습니다.
답: `{ "ok": true, "results": [{ "req": 0, "ok": true, "row": 12 }] }`
