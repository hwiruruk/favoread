# 셀럽 소개 재검증 대기 목록

2026-11-20 두 차례 검증(총 596건 중)을 거쳐 확정하지 못한 항목이에요. 나머지는 모두 검색으로 확인해 data/bios.json에 반영했어요.

## 확정하지 못한 항목

- 엄혜란: data.csv에 "엄혜란"(작별하지 않는다 추천)과 "염혜란"(모녀의 세계)이 따로 있어요. 염혜란의 오타로 보이니 data.csv 이름을 먼저 정정하세요. 소개는 정정 후 염혜란 항목과 맞추면 돼요.
- 김소현: 검색에 다른 김소현(1999년생)이 나와 기존 소개와 작품이 맞지 않았어요. 어느 김소현인지 먼저 정해야 해요.
- 이브: 동명이인 가수가 여럿이라 확정하지 못했어요.
- 이상헌: 검색 결과가 없었어요.
