# 코멘트 수집 — 출처를 읽고 추천 이유 뽑아내기

책 옆에 "왜 이 책을 추천했는지" 한 줄을 붙이기 위한 배치입니다.
출처 URL을 직접 받아와서 그 글이 다루는 책마다 한국어·영어 문장을 만듭니다.

```
출처 URL ──(HTML 본문 / 유튜브 자막)──▶ Claude ──▶ 책마다 한 줄 + 원문 인용
```

만들어진 것은 **전부 검수 대기 상태**입니다. 편집기(`/editor/`)의
**💬 코멘트 검수** 창에서 원문과 대조해 승인한 것만 사이트에 나갑니다.

## 처음 한 번 — 키 넣기

1. <https://console.anthropic.com> 에서 API 키를 발급합니다
2. 저장소 **Settings → Secrets and variables → Actions → New repository secret**
3. 이름 `ANTHROPIC_API_KEY`, 값에 발급받은 키를 붙여넣습니다

## 돌리는 법

GitHub 웹에서 **Actions → Fetch Book Comments → Run workflow**.

| 입력 | 뜻 |
|------|-----|
| `limit` | 이번에 읽을 출처 수. **처음엔 5로 해서 문장을 먼저 보세요** |
| `dry_run` | 켜면 결과만 찍고 파일은 안 바꿉니다. 첫 실행은 켜두는 걸 권합니다 |
| `refresh` | 지난번에 못 읽은 출처도 다시 조회 |
| `max_books` | 한 출처가 이 권수를 넘게 담고 있으면 건너뜁니다 (기본 3) |
| `effort` | 모델이 들이는 공. 본문에서 문장을 찾아 옮기는 일이라 `low`로 충분합니다 |

결과는 PR로 올라옵니다. 바뀌는 파일은 `data/comments.json` 하나입니다.

로컬에서 돌리려면:

```bash
export ANTHROPIC_API_KEY=sk-ant-...
pip install anthropic
python3 tools/fetch_comments.py --limit 5 --dry-run
```

## 왜 이유를 지어내지 않나

사이트는 "모든 리스트는 직접 열어서 확인할 수 있는 출처에서 나왔다"고
말하고 있습니다. 그럴듯한 이유를 채워 넣으면 그 말이 깨집니다.
그래서 세 가지를 지킵니다.

- 원문에 적힌 것만 씁니다. 배경지식으로 보태지 않습니다
- `quote` 칸에 근거가 된 **원문 문장을 그대로** 남깁니다. 검수할 때
  원문을 안 열어도 1차로 걸러낼 수 있습니다
- 추천 이유가 없으면 등급 `B`로 맥락만 적고, 그 책 얘기가 아예 없으면
  항목을 만들지 않습니다

`max_books` 가 있는 것도 같은 이유입니다. 한 출처가 수십 권을 담고 있으면
팬이 정리한 목록이고, 거기엔 애초에 이유가 없습니다.

## 출처별로 되는 것과 안 되는 것

| 출처 | 상태 |
|------|------|
| 기사·매거진·블로그·커뮤니티 | 본문을 그대로 읽습니다. 가장 잘 나옵니다 |
| 유튜브 | 자막을 받아옵니다. 자막이 없는 영상은 제목·설명만 보고, 그것도 없으면 건너뜁니다 |
| X(트위터)·인스타그램·틱톡 | 로그인 벽이라 건너뜁니다 (`misses` 에 `login-wall`) |

글이 아주 길면 책 제목이 나오는 구간만 잘라서 보냅니다.
그런 항목에는 `note` 에 그 사실이 적히고 검수 창에 경고로 뜹니다.

## 파일 형식

```json
{
  "_comment": "…이 파일이 뭔지 설명…",
  "_updated": "2026-09-21",
  "comments": {
    "황소윤(새소년)|거꾸로 사는 재미": {
      "ko": "헌책방에서 우연히 집어 든 책이라고 했어요. …",
      "en": "She said she found it by chance at a used bookstore. …",
      "quote": "헌책방에서 우연히 발견했는데 …",
      "source": "https://ch.yes24.com/article/details/45760",
      "grade": "A",
      "evidence": "fetch",
      "note": "",
      "status": "pending"
    }
  },
  "misses": {
    "https://x.com/…": "login-wall"
  }
}
```

- 키는 `"<연예인>|<도서명>"`이고 **둘 다 `data.csv`와 정확히 같아야** 합니다
- `evidence` — `fetch` 는 이 배치가 출처를 직접 읽은 것, `websearch` 는
  그 전에 검색 결과로 만든 초안입니다
- `misses` — 다음 실행 때 건너뛸 출처. 편집기에서 저장해도 지워지지 않습니다

## 이미 초안이 있는 출처는 건드리지 않습니다

한 출처의 책이 전부 `comments` 에 들어 있으면 그 출처는 아예 읽지 않습니다.
사람이 고친 문장을 덮어쓰지 않기 위해서입니다.
다시 뽑고 싶으면 `data/comments.json` 에서 그 항목을 지우고 돌리세요.

## 비용

출처 한 건에 요청 한 번입니다. 본문 길이에 따라 다르지만 대체로
입력 5천~2만 토큰, 출력 몇백 토큰 수준입니다. 시스템 프롬프트는
캐시되므로 여러 건을 이어 돌릴수록 단가가 내려갑니다.
`limit` 을 작게 두고 몇 번 돌려보면 실제 토큰 수가 로그에 찍힙니다.
