# 함께 읽기 카드 메이커 (`/together/`)

**내 최애가 읽은 책, 함께 읽기** — 최애 사진을 배경으로 그 사람이 읽은 책 표지를
스티커처럼 붙여 **인스타그램용 카드**를 만들고 PNG로 저장하는 공개 도구입니다.

`data.json`을 그대로 읽어 쓰기 때문에 별도 서버가 필요 없습니다. (정적 페이지)

- 홈(`index.html`)의 **‘함께 읽기 카드 만들기’** 배너에서 들어옵니다.
- 셀럽 페이지(`share/{이름}.html`)의 CTA는 `/together/?celeb={이름}`으로 바로 열어
  그 인물이 이미 선택된 상태로 시작합니다.

## 흐름
1. **① 최애 고르기** — 이름을 검색해 선택. 우리가 가진 인물 사진이 **기본 배경**으로 들어가고,
   그 사람이 읽은 책 목록이 아래에 나타납니다. 읽은 책 3권이 자동으로 배치돼요(글자는 없는 상태).
2. **② 배경 사진** — 기본 사진 대신 **직접 올린 사진**으로 교체 가능(`기본 사진` 버튼으로 되돌리기).
   비율이 제각각인 사진을 위해 **맞춤(꽉 채움/전체 보기) · 확대 · 가로·세로 초점 · 어둡게**를 조절합니다.
   사진 출처를 적으면 카드 오른쪽 아래에 표기돼요.
3. **③ 카드 설정** — 사이즈(**4:5 1080×1350 · 1:1 1080×1080 · 스토리 9:16 1080×1920**),
   테마 5종(⭐ 스티커 팝 · 🍡 파스텔 소다 · 🌃 네온 나이트 · 📔 크림 다이어리 · 🖤 모노 클래식).
   - **배경색**: 사진 여백과 별점·이모지 박스 바탕에 쓰이는 색
   - **글자색**: 제목 외곽선·말풍선 테두리·라벨에 쓰이는 색
   - 둘 다 기본은 `테마 기본값`이고, 체크를 끄면 프리셋이나 컬러 피커로 직접 고릅니다.
     테마를 다시 고르면 그 테마 기본값으로 돌아가요.
   - **책 표지 테두리**: 기본은 테두리 없이 그림자만. 켜면 테마에 맞는 테두리(크림 테마는 폴라로이드 흰 테두리)가 생깁니다.
   - 이미지 프록시, 하단 출처 표기.
4. **④ 함께 읽을 책** — 체크한 책이 카드에 붙습니다.
   - **책 보여주는 방식**: `▊ 책등`(기본) / `▢ 표지`. 책등은 X에서 유행한 '책등 인증샷'처럼
     책을 세워 책장으로 만듭니다. 예스24에 있는 책은 **실제 책등 이미지**가 들어가고,
     없으면 제목에서 만든 **색 책등**이 대신 들어가요 (아래 '책등' 항목 참고).
   - 표지 모드에서는 예전처럼 표지가 붙습니다. `자동 정렬`은 아래쪽에 가지런히 깔아 줘요.
   표지는 **원본 비율 그대로** 들어가서 잘리지 않습니다.
   - **표지 크기(전체)** 슬라이더로 붙어 있는 표지를 한꺼번에 키우고 줄입니다(60~220%).
     한 줄에 다 안 들어갈 만큼 키우면 카드 폭 안에서 **겹쳐서 부채처럼** 펼쳐져요.
   - 표지 하나만 따로 키우려면 카드에서 그 표지를 누르고 ⑤의 `크기(폭)`를 씁니다(90~900px).
     단, `자동 정렬`을 누르면 전체 크기 기준으로 다시 깔리니 개별 크기는 초기화됩니다.
5. **⑤ 스티커 & 글자** — 처음에는 **글자가 하나도 없습니다.** 사진과 책 표지만 있는 상태에서
   필요한 것만 골라 올리세요. 고르는 자리는 **미리보기 갤러리**입니다 — 이름만 적힌 버튼이
   아니라 **실제로 올라갈 모습**을 그대로 작게 그려 보여줍니다. 지금 테마·배경색·최애 이름이
   반영되므로, 누르면 보이는 그대로 카드에 올라와요.
   새로 올린 스티커는 앞의 글자 아래에 겹치지 않게 놓입니다.
   카드 위에서 **끌어서 이동**, 눌러서 선택한 뒤 글자·크기·기울기·앞뒤 순서를 바꿉니다.
   글자는 **엔터로 줄바꿈**됩니다.

   갤러리는 세 묶음입니다.

   - **요즘 스타일** — 두꺼운 테두리 없이 옅은 바탕에 진한 글자를 쓰는, 인스타에서 흔히 보는
     말랑한 스티커입니다. `둥근 박스` `단색 라벨` `얇은 테두리` `메모지` `테이프` `외곽선 글자`.
     바탕색과 글자색은 테마 색 하나에서 뽑아 섞으므로(`softBg` / `softFg`) 테마를 바꿔도 따라옵니다.
   - **그림 스티커** — 상자 없이 그림만 올립니다(곰돌이·커피·리본·달). **글자를 넣지 않아도**
     되는 쪽이라, 빈 구석을 채울 때 씁니다.
   - **기본** — 기존의 큰 제목 / 말풍선(몽글·알약·뾰족) / 별점 / 이모지 줄 / 작은 라벨.

   - 갤러리에 적힌 글자는 **예시**입니다. 그대로 써도 되고 지워도 됩니다.
   - **글자를 비워도 됩니다.** 말풍선·라벨·박스는 글자를 다 지워도 사라지지 않고
     빈 스티커로 남아서, 색 블록이나 띠만 올려두는 용도로 쓸 수 있어요.
     빈 스티커 크기는 `글자 크기`에 비례합니다(최소 크기를 `em`으로 잡아둠).
     `테이프`는 아예 글자 없이 시작합니다.
   - **가로 폭 · 높이**를 `자동`에서 끄면 px로 직접 정합니다. 넓고 납작한 띠나
     정사각형 색 블록을 만들 때 씁니다. 다시 `자동`을 켜면 글자에 맞춰 돌아가요.
   - 빈 스티커는 레이어 목록에 `(빈 칸)`으로 표시돼 카드에서 안 보여도 찾아 고를 수 있습니다.

   미리보기는 **실제 크기 그대로 그린 뒤 칸에 맞게 줄입니다**(`fitStickerPreviews`).
   배율을 미리 정해두면 글자 수가 다른 스티커끼리 크기가 들쭉날쭉해지기 때문입니다.

## 책등

예스24는 표지와 **같은 상품 ID**로 책등 이미지를 준다.

```
표지  https://image.yes24.com/goods/91901136/L
책등  https://image.yes24.com/goods/91901136/side
```

그래서 표지를 예스24에서 가져온 책은 URL만 바꿔 책등을 얻는다. 표지가 알라딘인 책은
예스24 상품 ID를 몰라 책등을 못 가져오므로, 제목에서 만든 색으로 책등을 그린다
(`spineTint` — 같은 제목이면 늘 같은 색).

책등 이미지를 색 책등 **위에 덮어** 두고 `onerror`로 스스로 지우게 했다. 그래서 예스24에
책등이 없거나 못 불러와도 자연스럽게 색 책등으로 떨어진다.

같은 규칙이 `generate.py`(셀럽 책장 페이지)와 `cardnews/app.js`에도 있다.

## 내보내기
상단 **⤓ PNG 저장** — 2배 해상도(예: 2160×2700)로 렌더링합니다.
외부 이미지를 캔버스에 그리려면 `이미지 프록시`가 켜져 있어야 해요.

## 구현 메모
- 카드는 항상 1080px 기준 좌표계에서 그리고, 미리보기만 `transform: scale()`로 줄입니다.
  드래그 이동량은 이 배율로 나눠 카드 좌표로 환산합니다.
- 이미지는 `<img object-fit>` 대신 background-image div로 그립니다 (html2canvas 호환).
  원본 크기를 미리 읽어 두었다가 상자 크기에 맞는 `background-size`를 직접 계산해
  어떤 비율의 사진이 와도 의도한 대로 채우거나 담습니다(`applyFits`).
- 업로드 사진은 긴 변 1600px로 축소합니다.
- 외부 의존: `html2canvas`, Google Fonts(Black Han Sans · Jua · Gaegu · Noto Serif KR · Space Grotesk),
  Pretendard, `images.weserv.nl`(이미지 프록시).

## 단축키 · 되돌리기

| 키 | 하는 일 |
| --- | --- |
| `Ctrl`+`Z` | 되돌리기 |
| `Ctrl`+`Shift`+`Z` / `Ctrl`+`Y` | 다시 하기 |
| `Ctrl`+`D` | 고른 스티커 복제 |
| `Ctrl`+`S` | PNG로 저장 |
| `←` `→` `↑` `↓` | 1px씩 옮기기 (`Shift`와 함께 10px) |
| `[` / `]` | 맨 뒤로 / 맨 앞으로 |
| `Delete` | 고른 것 지우기 |
| `Esc` | 선택 풀기 (글자 칸에서는 입력 끝내기) |

되돌리기는 상태를 통째로 JSON으로 찍어 쌓는 방식(최대 60단계)입니다.
항목이 수십 개뿐이라 이 방식이 가장 단순하고, 되돌린 뒤 UI까지 함께 맞춰 줍니다
(`snapshot` / `applySnapshot`).

기록 시점은 두 군데뿐입니다.

- 왼쪽 패널: `bindPanelUndo()`가 `.panel`에서 일어나는 `input`·`change`·`click`을
  **캡처 단계**로 한꺼번에 듣습니다. 핸들러가 값을 바꾸기 전에 찍히므로,
  옵션을 하나 추가해도 되돌리기 코드는 건드릴 필요가 없습니다.
- 카드 위: 드래그 시작(`bindCardEvents`)과 키보드 동작에서 직접 `pushUndo()`.

두 가지 장치로 목록이 지저분해지지 않게 합니다.

- **한 칸 미루기** — 찍은 것을 바로 쌓지 않고 `pending`에 들고 있다가, 다음에 부를 때
  그 사이에 실제로 바뀐 게 있을 때만 쌓습니다. 아무것도 안 바꾼 클릭은 버려집니다.
- **묶기(key)** — 같은 key로 0.7초 안에 또 부르면 한 번만 찍습니다. key는 화면에 있는
  그 DOM 요소마다 하나씩(`ctlKey`, WeakMap) 주므로 슬라이더를 죽 밀어도 한 단계입니다.

올린 사진(`data:` 주소)은 스냅샷마다 복사하면 수 MB씩 불어나므로, 따로 모아 두고
자리표시자로 바꿔 담습니다(`packBig` / `unpackBig`).

글자를 치는 중(`input[type=text]`·`textarea`)에는 단축키가 동작하지 않고 브라우저 기본
동작에 맡깁니다. 라디오·체크박스·슬라이더에 포커스가 있을 때는 `Ctrl` 조합만 가로채고
화살표 같은 낱개 키는 그 컨트롤이 쓰게 둡니다.
