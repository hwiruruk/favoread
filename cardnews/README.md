# Favorbook 카드뉴스 빌더

`data.json`에서 인물을 검색하면, 그 인물이 읽은 책과 정보를 불러와
**인스타그램용 카드뉴스**(표지 · 본문 · 출처)를 한 번에 만들고 PNG로 내보내는 도구입니다.

브라우저에서 `/cardnews/`로 열면 됩니다. (정적 페이지 · `noindex`)

## 슬라이드 구성
표지 → 본문(책별) → **출처**(텍스트/이미지 구분) → **홍보**(최애의 독서 홈페이지).

## 흐름
1. **① 인물 검색** — 이름을 입력하면 자동완성에서 선택.
2. **② 선택된 인물** — 표지 사진은 stored `imageUrl`을 쓰고, 필요하면 직접 업로드해 교체.
   - **표지 이미지 출처**: 첫 장 왼쪽 하단에 들어갈 출처(인물 이미지 URL에서 자동 추정, 직접 수정 가능)
3. **③ 카드 설정**
   - **테마**: Z세대 레이아웃 5종 — 📰 에디토리얼(기본) · ⭐ 스티커 팝 · 💿 Y2K 사이버 · ✏️ 다이어리 · 🗞 뉴트로 진.
     테마마다 폰트·테두리·말풍선·장식이 통째로 바뀝니다. 고르면 배경색과 포인트 색이 그 테마 기본값으로 초기화돼요.
   - **언어**: 한국어 / **English** (해외 K-pop·K-drama 팬 유입용. 책 제목·저자는 `title_en`/`author_en`로 자동 전환)
   - 표지 제목/부제 (자동 채움, 한글 조사·언어 자동 처리. 직접 수정하면 자동 갱신 멈춤). **엔터로 줄바꿈**됩니다.
   - **배경색**: 프리셋 12종 + 직접 선택(컬러 피커)
   - **글자색**: 기본은 배경 명도에 맞춘 자동. `배경에 맞춰 자동`을 끄면 프리셋·컬러 피커로 직접 지정
   - **포인트 색**: 테마 장식(테두리·말풍선·강조)에 쓰이는 색. 테마 기본값 또는 직접 지정
   - 사이즈: **4:5 세로 (1080×1350)** / **1:1 정사각 (1080×1080)**
   - **이미지 맞춤**: 전체 보기(안 잘림, `contain`) / 꽉 채움(`cover`) · **표지 사진 확대** 슬라이더(100~260%)
   - **표지 장의 책**: `▊ 책등`(기본) / `▢ 표지`. 책등은 책을 세워 책장처럼 만듭니다.
     예스24에 있는 책은 실제 책등 이미지, 없으면 제목에서 만든 색 책등이 들어가요.
     (표지와 같은 상품 ID로 `/L` → `/side`. 자세한 건 `together/README.md`의 '책등' 항목)
   - **표지 배치** (표지 모드일 때만): 한 줄 / **2열 · 3열 · 4열**. 열을 늘리면 표지가 작아지는 대신 더 많이 들어가요
     (최대 열×5행). 표지 크기는 세로로 남은 자리와 가로로 남은 자리 중 **좁은 쪽**에 맞춰 정해집니다 —
     좌우 분할(split) 표지는 왼쪽 단이 1080의 53%뿐이라 열을 늘리면 가로가 먼저 걸려요.
   - **흑백 톤** · **표지에 책 표지**(첫 장에 읽은 책 표지 노출) · **출처 슬라이드** · **홍보 슬라이드** · **이미지 프록시**(weserv)
4. **④ 책 선택 & 편집** — 체크한 책이 카드가 됩니다. 펼치면:
   - **언급 대목(인용문)**: 인물이 책을 언급/추천한 문장을 붙여넣기 (옆의 *출처 열기 ↗* 로 원문 확인).
     **엔터를 치면 카드에서도 그대로 줄이 바뀝니다.**
   - **출처**: URL에서 **매체명·유형·날짜**를 자동 인식해 미리 채워 줌. 손으로 다듬을 수 있음.
   - **이 카드 사진(선택)**: 카드마다 다른 사진을 넣을 수 있어요. 파일 업로드 또는 이미지 URL.
     사진이 있으면 그 카드는 **왼쪽 = 책 · 오른쪽 = 사진** 2단 레이아웃으로 바뀝니다.

## ⑤ 스티커 & 글자 (자유 배치 레이어)

`/together/`(함께 읽기 카드 만들기)의 자유 배치 기능을 카드뉴스에도 들여왔습니다.
카드 위 어디든 스티커를 얹을 수 있어요.

고르는 자리는 **미리보기 갤러리**입니다 — 이름만 적힌 버튼이 아니라 **실제로 올라갈 모습**을
그대로 작게 그려 보여줍니다. 지금 배경색·포인트색·셀럽 이름이 반영되므로, 누르면 보이는 그대로
올라와요. 세 묶음입니다.

- **요즘 스타일** — 두꺼운 테두리 없이 옅은 바탕에 진한 글자를 쓰는, 인스타에서 흔히 보는
  말랑한 스티커. `둥근 박스` `단색 라벨` `얇은 테두리` `메모지` `테이프` `외곽선 글자`.
  바탕색·글자색은 팔레트 색 하나에서 섞어 뽑으므로 배경색을 바꿔도 따라옵니다.
- **그림 스티커** — 상자 없이 그림만(곰돌이·커피·리본·달). **글자를 넣지 않아도** 되는 쪽입니다.
- **기본** — 기존의 큰 제목 / 말풍선 / 별점 / 이모지 줄 / 작은 라벨.

갤러리에 적힌 글자는 예시라 그대로 써도 되고 지워도 됩니다. 미리보기는 실제 크기로 그린 뒤
칸에 맞게 줄입니다(`fitStickerPreviews`) — 배율을 미리 정해두면 글자 수가 다른 스티커끼리
크기가 들쭉날쭉해지기 때문입니다.

- **올릴 장**을 고르고 누르면 그 장에 올라갑니다. 표지·본문뿐 아니라 **출처·홍보 장**에도 됩니다.
- 스티커는 **장마다 따로** 기억됩니다. 카드 위에서 **끌어서 이동**, **휠로 크기** — 본문 요소와 같은 조작이에요.
- 카드 위의 스티커를 누르면 패널에서 글자·크기·기울기·앞뒤 순서를 바꿉니다.
- **글자를 다 지워도** 말풍선·라벨은 빈 스티커로 남습니다. 색 블록이나 띠를 얹는 용도예요.
  빈 스티커 크기는 `글자 크기`에 비례합니다.
- **가로 폭 · 높이**를 `자동`에서 끄면 px로 직접 정합니다.
- 말풍선 색은 **포인트 색 / 배경색 / 글자색** 중에서 고르므로 테마를 바꿔도 따라옵니다.
- 빈 스티커는 레이어 목록에 `(빈 칸)`으로 표시돼 카드에서 안 보여도 찾아 고를 수 있습니다.
- 선택 표시(파란 점선)는 **미리보기에만** 그립니다. PNG에는 나가지 않아요.
- 스티커는 `💾 저장(JSON)`에 함께 담기고 `📂 열기`로 복원됩니다.

## 범용 이미지 맞춤 툴
가로/세로/정사각 등 **비율이 제각각인 사진**을 그대로 넣어도 되도록, 원본 크기를 읽어 상자에 맞는
배율을 직접 계산합니다(`applyPhotoFits`). 사진마다 아래를 조절할 수 있어요.
- **맞춤**: 꽉 채움(`cover`) / 전체 보기(`contain`, 안 잘림)
- **확대**: 100~300%
- **가로·세로 초점**: 0~100% (얼굴이 잘리지 않게 중심 이동)
- **사진 폭**: 카드에서 사진이 차지할 비율 28~62%

업로드한 사진은 긴 변 1600px로 자동 축소해 저장/내보내기 용량을 줄입니다.

책 표지는 **원본 비율에 맞춰 상자 크기가 정해집니다.** 표지가 정사각에 가깝든 길쭉하든
테두리와 그림자가 표지에 딱 붙어요. (상자를 고정 비율로 두면 표지 옆에 배경색 여백이 남고
그림자만 상자를 따라 어긋나 보입니다.)
사진·책 표지 상자의 **빈 공간은 카드 배경색과 똑같이** 칠해져서, 전체 보기(`contain`)로 넣어도
사진 주변이 다른 색으로 떠 보이지 않습니다.

## 마우스로 직접 조정
미리보기 카드 위에서 바로 손볼 수 있습니다. 조정값은 장마다 따로 기억되고,
테마·색·사이즈를 바꿔도 그대로 남습니다.

| 대상 | 끌기 | 휠 |
|---|---|---|
| 표지 제목·부제 | 위치 이동 | 크기 (0.4~3배) |
| 표지의 책 표지 묶음 | 위치 이동 | 크기 |
| 본문 책 표지 | 위치 이동 | 크기 |
| 본문 책 제목·저자 | 위치 이동 | 크기 |
| 언급 대목(인용구) | 위치 이동 | 크기 |
| 인물 사진 · 카드별 사진 | 초점 이동 | 확대 (1~4배) |
| ⑤에서 올린 스티커 | 위치 이동 | 글자 크기 (20~200px) |

- 사진은 **움직일 여지가 있는 방향으로만** 따라옵니다. 예를 들어 꽉 채움에서 세로로 딱 맞으면
  위아래로는 움직이지 않아요.
- 마우스로 사진을 만지면 ③·④ 패널의 확대·초점 슬라이더도 같은 값으로 따라갑니다.
- 되돌리려면 각 장 아래의 **↺ 조정 초기화**를 누르세요. (그 장의 위치·크기·사진 초점이 모두 기본값으로)
- 조정값은 `💾 저장(JSON)`에 함께 저장되고 `📂 열기`로 그대로 복원됩니다.

## 출처 표기
출처 URL 하나에서 네 가지를 뽑아 카드에 적습니다.

| 항목 | 어디서 | 예 |
|---|---|---|
| 매체명 | 호스트 | `wkorea.com` → **W KOREA** |
| 계정명 | 경로의 `@핸들`이나 첫 조각, 티스토리는 서브도메인 | `brunch.co.kr/@parkaezey/82` → **@parkaezey** |
| 제목 | 경로 슬러그, 영상은 oEmbed | `…/미야오-가원이-만난-봄날/` → **미야오 가원이 만난 봄날** |
| 날짜 | 경로의 `2024/05/12` 또는 `20240512` | **2024.05.12** |

- 매체 인식 대상: VOGUE/ELLE/W/GQ/얼루어 등 매거진, 서울경제·한경·조선 등 신문,
  유튜브·인스타그램·더쿠·네이버 블로그, 예스24/밀리/교보/알라딘 등 도서 플랫폼.
- 계정명은 인스타그램·X·틱톡·스레드·유튜브·네이버 블로그/포스트/카페·브런치·티스토리·위버스에서 잡습니다.
  `p`, `watch`, `status` 같은 기능 이름은 계정으로 보지 않습니다.
- 제목은 **글 번호나 게시물 ID를 걸러냅니다.** 한글이 들어갔거나 영문 단어가 둘 이상인 슬러그만 제목으로 받아들여요.
- **유튜브·비메오**는 공개 oEmbed를 불러 실제 **영상 제목과 채널명**을 채웁니다.
  체크된 책에 대해 자동으로 시도하고, 실패하면(오프라인·차단) URL에서 뽑은 값만 씁니다.
- 네 칸 모두 ④에서 직접 고칠 수 있고, `↻ URL에서 다시 읽기`로 되돌립니다.

카드에는 두 줄로 들어갑니다.
```
SOURCE   VOGUE KOREA · @favoritesbook · 2024.05.12
         「미야오 가원이 만난 봄날」
```
출처 슬라이드에는 `《책 제목》 — 매체 · 계정 · 날짜` 아래에 「페이지 제목」이 붙고,
`⧉ 원고 복사`에는 **출처 URL까지** 함께 담깁니다.

## 내보내기
- 슬라이드별 **⤓ PNG** 버튼, 또는 상단 **⤓ 전체 PNG (ZIP)**.
- 출력 해상도는 2배(예: 2160×2700)로 렌더링됩니다.

## 디자인
- 기본 테마는 antiegg 풍 에디토리얼: 따뜻한 아이보리 페이퍼, 잉크 블랙, 헤어라인 구분선,
  Noto Serif KR(제목·인용) + Pretendard(라벨·메타) + Cormorant Garamond(번호).
- 테마 폰트: Black Han Sans · Jua · Gaegu · Space Grotesk (Google Fonts).
- 외부 의존: `html2canvas`, `JSZip`, Google Fonts, Pretendard, `images.weserv.nl`(이미지 프록시).

| 키 | 하는 일 |
| --- | --- |
| `Ctrl`+`Z` | 되돌리기 |
| `Ctrl`+`Shift`+`Z` / `Ctrl`+`Y` | 다시 하기 |
| `Ctrl`+`D` | 고른 스티커 복제 |
| `Ctrl`+`S` | 전체 ZIP 내려받기 (`Shift`와 함께면 프로젝트 저장) |
| `←` `→` `↑` `↓` | 3px씩 옮기기 (`Shift`와 함께 30px) |
| `+` / `-` | 고른 스티커 글자 크기 |
| `[` / `]` | 맨 뒤로 / 맨 앞으로 |
| `Delete` | 고른 스티커 빼기 |
| `Esc` | 선택 풀기 (글자 칸에서는 입력 끝내기) |

되돌리기는 상태를 통째로 JSON으로 찍어 쌓는 방식(최대 60단계)입니다.
항목이 수십 개뿐이라 이 방식이 가장 단순하고, 되돌린 뒤 UI까지 함께 맞춰 줍니다
(`snapshot` / `applySnapshot`). 담는 항목은 프로젝트 저장(`saveProject`)과 같습니다 —
스티커뿐 아니라 왼쪽 설정·책 고르기·마우스 조정까지 함께 되돌아갑니다.

기록 시점은 두 군데뿐입니다.

- 왼쪽 패널: `bindPanelUndo()`가 `.panel`에서 일어나는 `input`·`change`·`click`을
  **캡처 단계**로 한꺼번에 듣습니다. 핸들러가 값을 바꾸기 전에 찍히므로,
  옵션을 하나 추가해도 되돌리기 코드는 건드릴 필요가 없습니다.
- 카드 위: 드래그 시작·휠·조정 초기화(`bindAdjust` / `resetAdj`)와 키보드 동작에서 직접 `pushUndo()`.

두 가지 장치로 목록이 지저분해지지 않게 합니다.

- **한 칸 미루기** — 찍은 것을 바로 쌓지 않고 `pending`에 들고 있다가, 다음에 부를 때
  그 사이에 실제로 바뀐 게 있을 때만 쌓습니다. 아무것도 안 바꾼 클릭은 버려집니다.
- **묶기(key)** — 같은 key로 0.7초 안에 또 부르면 한 번만 찍습니다. key는 화면에 있는
  그 DOM 요소마다 하나씩(`ctlKey`, WeakMap) 주므로 슬라이더를 죽 밀어도 한 단계입니다.

올린 사진(`data:` 주소)은 스냅샷마다 복사하면 수 MB씩 불어나므로, 따로 모아 두고
자리표시자로 바꿔 담습니다(`packBig` / `unpackBig`).

글자를 치는 중(`input[type=text]`·`textarea`)에는 단축키가 동작하지 않고 브라우저 기본
