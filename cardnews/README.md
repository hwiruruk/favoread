# Favoread 카드뉴스 빌더

`data.json`에서 인물을 검색하면, 그 인물이 읽은 책과 정보를 불러와
**인스타그램용 카드뉴스**(표지 · 본문 · 출처)를 한 번에 만들고 PNG로 내보내는 도구입니다.

브라우저에서 `/cardnews/`로 열면 됩니다. (정적 페이지 · `noindex`)

## 슬라이드 구성
표지 → 본문(책별) → **출처**(텍스트/이미지 구분) → **홍보**(최애의 독서 홈페이지).

## 흐름
1. **① 인물 검색** — 이름을 입력하면 자동완성에서 선택.
2. **② 선택된 인물** — 표지 사진은 stored `imageUrl`을 쓰고, 필요하면 직접 업로드해 교체.
   - **표지 이미지 출처**: 첫 장 왼쪽 하단에 들어갈 출처(인물 이미지 URL에서 자동 추정, 직접 수정 가능)
3. **③ 카드 설정**
   - **언어**: 한국어 / **English** (해외 K-pop·K-drama 팬 유입용. 책 제목·저자는 `title_en`/`author_en`로 자동 전환)
   - 표지 제목/부제 (자동 채움, 한글 조사·언어 자동 처리. 직접 수정하면 자동 갱신 멈춤)
   - **배경색**: 프리셋 8종 + 직접 선택(컬러 피커). 배경 명도에 따라 글자색이 자동으로 맞춰짐
   - 사이즈: **4:5 세로 (1080×1350)** / **1:1 정사각 (1080×1080)**
   - **이미지 맞춤**: 전체 보기(안 잘림, `contain`) / 꽉 채움(`cover`)
   - **흑백 톤** · **표지에 책 표지**(첫 장에 읽은 책 표지 노출) · **출처 슬라이드** · **홍보 슬라이드** · **이미지 프록시**(weserv)
4. **④ 책 선택 & 편집** — 체크한 책이 카드가 됩니다. 펼치면:
   - **언급 대목(인용문)**: 인물이 책을 언급/추천한 문장을 붙여넣기 (옆의 *출처 열기 ↗* 로 원문 확인)
   - **출처**: URL에서 **매체명·유형·날짜**를 자동 인식해 미리 채워 줌. 손으로 다듬을 수 있음.

## 출처 표기
URL 호스트를 보고 매체를 인식합니다 — VOGUE/ELLE/W/GQ/얼루어 등 매거진, 서울경제·한경·조선 등 신문,
유튜브·인스타그램·더쿠·네이버 블로그, 예스24/밀리/교보/알라딘 등 도서 플랫폼.
경로에 `2024/05/12` 또는 `20240512` 형태가 있으면 날짜도 자동 추출합니다.
표기 형식: `매체명 · 유형 · 날짜` (예: **VOGUE KOREA · 인터뷰 · 2024.05.12**).

## 내보내기
- 슬라이드별 **⤓ PNG** 버튼, 또는 상단 **⤓ 전체 PNG (ZIP)**.
- 출력 해상도는 2배(예: 2160×2700)로 렌더링됩니다.

## 디자인
- antiegg 풍 에디토리얼: 따뜻한 아이보리 페이퍼, 잉크 블랙, 헤어라인 구분선,
  Noto Serif KR(제목·인용) + Pretendard(라벨·메타) + Cormorant Garamond(번호).
- 외부 의존: `html2canvas`, `JSZip`, Google Fonts, Pretendard, `images.weserv.nl`(이미지 프록시).
